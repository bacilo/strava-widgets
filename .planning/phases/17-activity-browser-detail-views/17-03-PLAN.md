## Trust Boundaries

| Boundary | Description |

| URL hash `?month=` parameter → calendar state | Attacker-controllable via a crafted/shared link |
| `data/dashboard/index.json` rows → day aggregation | Self-published static data, but `startDateLocal` shape varies by era and may be malformed for a bad record |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-URL-04 | Tampering | `parseMonthParam` | mitigate | Strict `/^\d{4}-\d{2}$/` allow-list plus a 1–12 month range and a 1900–2999 year range; any other value falls back to the injected `now` |
| T-17-CAL-01 | Denial of Service (client) | `buildMonthGrid` loop bounds | mitigate | Grid size is derived from the validated month (max 6 week rows), never from a parsed parameter, so no attacker-controlled value can drive an unbounded allocation |
| T-17-CAL-02 | Tampering | Malformed `startDateLocal` in a row | mitigate | `activityDayKey` returns null for unparseable input and `buildMonthGrid` skips those rows rather than throwing or producing an off-by-one day |
| T-17-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (17-RESEARCH.md § Package Legitimacy Audit) |
