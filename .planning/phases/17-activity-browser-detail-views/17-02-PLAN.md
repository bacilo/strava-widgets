Query-string contract (D-07 — these exact param names are the shareable-URL contract):
`sort`, `dir`, `page`, `q`, `from`, `to`, `dmin`, `dmax`, `pmin`, `pmax`, `tmin`, `tmax`.
`from`/`to` are `YYYY-MM-DD` strings; `dmin`/`dmax` are kilometres (may be fractional);
`pmin`/`pmax` are integer seconds-per-km; `tmin`/`tmax` are integer minutes.

- `export function parseListQuery(query: URLSearchParams): ListState` — total function, never
  throws. `sort` accepted only if it is a member of `SORT_KEYS`, else `'date'`. `dir` accepted only
  if `'asc'` or `'desc'`, else `DEFAULT_DIR[sort]`. `page` parsed with `Number.parseInt`, accepted
  only if `Number.isInteger` and `>= 1`, else 1. Each numeric filter parsed with `Number()` and
  accepted only if `Number.isFinite` and `>= 0`, else `null` — an unparseable value drops that one
  filter without affecting the others (the `buildExclusionIndex` tolerance discipline from
  `src/analytics/best-effort-exclusions.ts`). `from`/`to` accepted only if they match
  `/^\d{4}-\d{2}-\d{2}$/`. `q` is taken verbatim but trimmed and truncated to 200 chars.
  Never index a parsed key into an object literal (no `__proto__` reachability).
- `export function serializeListQuery(state: ListState): URLSearchParams` — inverse of the above,
  omitting every parameter whose value equals the default (so the canonical clean URL has no query).

Sorting:
- `export function compareRows(a, b, sort: SortKey, dir: SortDir): number`
- `export function sortRows(rows: readonly DashboardIndexRow[], sort: SortKey, dir: SortDir): DashboardIndexRow[]`

  keys (`pace`, `avgHr`). Sort field mapping: `date` → `startDateLocal` compared as a normalized

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL hash query string → list state | Fully attacker-controllable (a shared/crafted link); crosses into sort keys, page numbers, and numeric comparisons |
| Athlete-authored `row.name` → search matching | Untrusted free text from the archive; matched against, and later rendered by, the DOM layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-URL-01 | Tampering | `parseListQuery` sort key | mitigate | `sort` accepted only if `SORT_KEYS.includes(value)`; unknown values (including `__proto__`, `constructor`) fall back to `'date'` and are never used as an object index |
| T-17-URL-02 | Denial of Service (client) | `parseListQuery` page/numeric filters | mitigate | `page` clamped to `[1, totalPages]` by `paginate`; numeric filters require `Number.isFinite` so `Infinity`/`NaN` can never propagate into a comparison or a slice length |
| T-17-URL-03 | Tampering | `q` free-text parameter length | mitigate | `q` trimmed and truncated to 200 characters before it reaches any matcher or chip label |
| T-17-VW-01 | Tampering (XSS) | Chip labels derived from `q` | mitigate | `buildFilterChips` returns plain strings only; the DOM layer (plan 17-09) is contractually required to write them with `textContent` — no HTML is produced in this module |
| T-17-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (17-RESEARCH.md § Package Legitimacy Audit) |
</threat_model>
