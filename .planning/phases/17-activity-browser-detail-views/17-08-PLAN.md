<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hash query string → rendered list state | Attacker-controllable via a crafted or shared link; drives sort key, page number, and DOM construction |
| Athlete-authored `row.name` → table cell and anchor label | Untrusted free text from the archive, now rendered at two new sites (table cell, `aria-label`) in addition to the existing card |
| `row.id` → `#/activity/{id}` href and click handler | Comes from the published index; still becomes a URL, so it must not be interpolated unvalidated into markup |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-VW-01 | Tampering (XSS) | `buildTableRow` Activity cell and `aria-label` | mitigate | Name is written via `textContent` and `setAttribute('aria-label', ...)`; the file contains zero `innerHTML` assignments (asserted by grep). Deliberately deviates from `route-utils.ts`'s `formatPopupContent` unescaped-interpolation pattern, per T-16-VW-01 |
| T-17-URL-01 | Tampering | Sort key / direction from the query string | mitigate | Consumed only through `parseListQuery`, which allow-lists against `SORT_KEYS` (plan 17-02, unit-tested); this view never indexes a raw query value into an object |
| T-17-URL-02 | Denial of Service (client) | Page number driving DOM construction | mitigate | Rendering uses `paginate`'s `clampedPage` and `pageItems`, so a `?page=99999` or `?page=-1` can never drive a large or negative slice; at most `PAGE_SIZE` rows are ever built |
| T-17-VW-03 | Tampering | `row.id` interpolated into an href | mitigate | The href is assigned via the `href` property on a created `<a>` element (never an HTML string), and `detail-client.ts`'s `isValidActivityId` chokepoint still gates any actual fetch, so a malformed id fails closed at load time rather than executing |
| T-17-VW-04 | Denial of Service (feature) | Stale render painting a superseded view | mitigate | The Phase 16 `mountedContainer !== ctx.container` guard is preserved after both the catch and the success path, and additionally gates the D-08 scroll/focus side effects (WR-01 lineage) |
| T-17-SC | Tampering | npm/pip/cargo installs | accept | No packages installed this phase (17-RESEARCH.md § Package Legitimacy Audit) |
