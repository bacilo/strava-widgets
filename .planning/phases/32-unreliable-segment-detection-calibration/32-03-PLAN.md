Detector semantics the recount must reproduce by its OWN code (restated from plan 32-02, NOT imported):
- Covered pairs are pairs outside every gap. A step folds zero-advance and zero-duration covered pairs
  into the next pair that makes metres > 0 and seconds > 0. Folding never crosses a gap.
- A step is fast iff metres > speedLimitMps × seconds. A run is a maximal set of contiguous fast steps.
  A burst is a run with metres − speedLimitMps × seconds > excessFloorMetres.
- A burst touches a gap only if it ends on the gap's start sample or starts on its end sample.
  Contiguous burst/gap chains are one segment; a gap touching no burst is not a segment.
- metres/seconds of every segment and part are endpoint differences d[end]−d[start], t[end]−t[start].
