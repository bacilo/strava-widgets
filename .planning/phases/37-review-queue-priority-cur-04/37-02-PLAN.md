## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser tab to curate server (127.0.0.1:4173) | Any page in the developer's browser can attempt a request; DNS rebinding can present a foreign hostname |
| request body to committed file | Untrusted JSON (reason, fingerprint) is persisted into a tracked file |
| test suite to working tree | Real-socket tests could write tracked files if the paths are not injected |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-04 | Spoofing / Tampering (cross-origin write, DNS rebinding) | PUT/DELETE /__curate/reviewed/:id | mitigate | Shared resolveWriteTarget calls isTrustedOrigin(req, EXPECTED_HOST) first; 403 tested cross-origin and with a mismatched Host |
| T-37-05 | Information disclosure (private review text read cross-origin) | GET /__curate/reviewed | mitigate | Origin-gated like /__curate/queue (not ungated like /health); 403 tested |
| T-37-06 | Tampering (malicious id / path traversal) | id decoding | mitigate | isValidCurateActivityId; write target is a constant path, never derived from the id; "../x" and "__proto__" tested 400 |
| T-37-07 | Tampering (stored XSS / injection via fingerprint or reason) | normalizeFingerprint, normalizeReason | mitigate | Fingerprint charset regex and 1000-char cap; reason trimmed and capped at MAX_REASON_CHARS; rendering is textContent-only (plan 37-06) |
| T-37-08 | Denial of service (oversized body) | readJsonBody | mitigate | Existing MAX_BODY_BYTES; 413 tested |
| T-37-09 | Tampering (silent overwrite of a corrupt committed file) | readReviewedFile | mitigate | Invalid JSON or a non-array `reviewed` throws, the handler returns 500, and the corrupt bytes are asserted unchanged |
