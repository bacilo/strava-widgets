## Sampling Rate

- **After every task commit:** the touched test file, plus the logic suite once it exists
- **After every plan wave:** `npm test`, then `git status --porcelain -- data .planning` showing no unintended changes
- **Before `/gsd-verify-work`:** full suite green; both ING-01 gate directions demonstrated in a scratch copy with recorded output
- **Max feedback latency:** 30 seconds
- **Filters:** no `-t` filters. Every `--config`/file-filtered run records its matched file and test counts (a 0-match run exits 0).
