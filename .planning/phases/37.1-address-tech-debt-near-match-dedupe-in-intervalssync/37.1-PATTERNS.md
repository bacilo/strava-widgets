### `src/exports/near-match.ts` (utility, transform)

**Analog:** `src/exports/reconcile.ts`

**Constant to move** (line 24). The new module owns it; `reconcile.ts` re-exports:
```typescript

```

**Signed-delta and inclusive-bound convention to preserve** (reconcile.ts 131-150). Note `deltaS = run.startEpoch - best` (new minus existing) and the bound is inclusive (`<=`); exact (0) is handled earlier by the caller:
```typescript
if (best !== undefined && Math.abs(best - run.startEpoch) <= tolerance) {
  near.push({
    sourceId: run.sourceId,
    startEpoch: run.startEpoch,
    archiveId: idByEpoch.get(best)!,
    deltaS: run.startEpoch - best,
  });
```
The importer uses `delta >= 1 && delta <= NEAR_MATCH_TOLERANCE_S` on `Math.abs` (fit-import.ts 259-260). `findNearMatch` must give `1 <= |delta| <= tolerance` and treat a non-finite epoch as no match (RESEARCH Security row).

**Tolerance injection precedent** (reconcile.ts line 90-92): `opts: { nearToleranceS?: number }` then `const tolerance = opts.nearToleranceS ?? NEAR_MATCH_TOLERANCE_S;`. Mirror as a default parameter `tolerance = NEAR_MATCH_TOLERANCE_S`.

**Existing candidate shape** to reuse rather than invent (reconcile.ts 34-37):
```typescript

  id: string;
  epoch: number;
}
```
Header-comment style: reconcile.ts 4-22 (block JSDoc listing rules). Do not import `fs`/`path` in the new module.
