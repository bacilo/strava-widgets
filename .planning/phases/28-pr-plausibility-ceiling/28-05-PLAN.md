<objective>
Restructure `computeBestEfforts` into a strict three-pass shape — accumulate, derive the ceiling
exactly once, then filter-and-flag — and route every rejection through one shared demotion path so
no effort is ever deleted again.

Purpose: this is the phase's centre. It closes PR-01's determinism, PR-02's non-circularity and
PR-03's never-delete rule in one function, and it fixes a currently-shipping defect: today
`rejected.push(...); continue` silently removes 34 efforts across 28 activities from the archive,
and nothing in the dashboard reads the array they land in — the archive's most flagrantly broken
efforts are the only ones that can never be seen.

Output: a three-pass `compute-best-efforts.ts` with persisted ceilings, and the four demonstrated
regression suites the ROADMAP's success criteria name.
</objective>
