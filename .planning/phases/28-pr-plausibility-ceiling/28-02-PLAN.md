<objective>
Land the data model for a demotion — a separate field from `excludedFromRecords`, carrying which
guard fired and why — and the pure, DOM-free dashboard logic that reads it, before any compute or
rendering code depends on it.

Purpose: this is the contract every later plan in the phase builds against. Landing it first means
plan 28-04 (rendering) and plan 28-05 (the three-pass restructure) can run in parallel against a
fixed shape instead of exploring for one. It also moves the Best Efforts panel's badge STRINGS out
of the DOM builder into a testable pure function, which is the structural half of D-09's
"fix the `buildPrFlagsCell` hazard rather than extend it" — this repository runs vitest with
`environment: 'node'` and has no DOM library, so a string decided inside a DOM builder is a string
no test can ever read.

Output: extended types, two extended pure logic modules, and their tests.
</objective>
