<objective>
Put a two-option scope control above the Records PR tables and make the seven per-distance tables
re-rank within the selected year.

Purpose: OVR-03 asks to switch "the records section" between all-time and current-year views.
D-01 resolved that onto `buildPrTablesSection` (`records.ts:567`) because Overview has no records
section — its Recent PRs card already shows only recent PRs, so year-scoping it would be close to a
no-op. The PR tables are the only surface where a year scope changes what a reader sees.

This is a client-side filter over data already in memory: `records.ts` already fetches the whole
`best-efforts.json`, and `PRRankingEntry` already carries `startDate`. No fetch, no pipeline, no
new payload.

Output: a `.segmented` All time / This year group above the tables, a pure filter-and-re-rank
function in `records-logic.ts`, and an empty state that finally names its own distance.
</objective>
