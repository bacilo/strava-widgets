<objective>
Retire Overview's private row renderer into the shared one, closing OVR-01 and OVR-02 at the call
sites.

Purpose: D-05 is Phase 20's D-07 reasoning applied one level up — two live models for the same
visual row is precisely the inconsistency this phase exists to remove. `renderRecentPrRow`
(`overview.ts:118`) and `renderActivityRow` (`list.ts:324`) build the same `<a class="activity-row">`
with the same class names, and `recentPrRowAriaLabel` (`overview.ts:101`) and
`activityRowAriaLabel` (`list.ts:290`) differ only in which badge array they fold. After this plan
Overview builds no row DOM at all, and "Recent Activities follows the same structure as Recent PRs"
is true by construction rather than by inspection.

The retirement is not free: three existing test assertions in `row-semantics.test.ts` and both
describes in `overview.test.ts` are written against the code being deleted. Repointing them is
Tasks 2 and 3, not incidental cleanup.

Output: two card builders, one shared renderer, distinct surfaces, and guards that keep a future
edit from reintroducing a second row model.
</objective>
