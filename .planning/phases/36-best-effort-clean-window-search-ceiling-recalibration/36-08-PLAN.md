reason must be reachable WITHOUT leaving the detail view, and the ranked figure must never be presented
as if nothing changed.

wiring guard that proves the DOM builder renders it.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a shard written by an older or newer pipeline to the render path | Shards are read as untyped JSON; one predating this phase carries no `contaminated` key and one from a future phase could carry an unknown shape |
| two distinct claims sharing one visual channel | A moved effort and a rejected effort are different statements; a shared badge class or a shared `descriptionIdSuffix` collapses them for both sighted and assistive-technology readers |
| a pure spec module to a DOM builder that cannot be unit-tested | `environment: 'node'` means the DOM path is only assertable by source text, so a second badge code path would be invisible to the suite |

No package is installed and no network route is added, so the Package Legitimacy Gate and a
`T-36-SC` row do not apply to this plan.
