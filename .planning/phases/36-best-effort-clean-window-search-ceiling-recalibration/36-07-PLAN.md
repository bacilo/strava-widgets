<objective>
Close 28 WR-06: stop an ordinary local command from rewriting the tracked ceiling-state file.

Purpose: `compute-best-efforts.ts` rewrites `data/best-effort-ceiling.json` whenever population, p90 or
any ceiling moves — and p90 moves with most new runs, because it is an observed data point. That file
is CI-committed, and a local run overwrites it with a baseline CI never produced. 28 WR-06 records this
as "partially resolved — the hazard is now documented, not removed." This phase moves every ceiling at
once and then asks the developer to sign a sha256 over artifacts derived from that baseline, so the
carried-forward hazard bites hardest here.

Output: an explicit, default-off option; a per-invocation CLI flag threaded through the step table; the
one CI invocation that opts in; and a both-directions proof.

Requirement-tick safety: this plan ticks nothing and edits no planning document. Skip any end-of-plan
`requirements mark-complete` call.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a local developer command to a CI-committed tracked file | `data/best-effort-ceiling.json` is written by CI and read as the previous-run baseline; a local run overwrites it with a baseline CI never produced |
| a per-invocation flag to a module-level step table | The step table is a module constant whose closures capture only module state; an ambient `process.argv`/`process.env` read inside a closure would be untestable without mutating globals |
| an untyped `.mjs` caller to `ComputeBestEffortsOptions` | The diff and recount generators call the compiled function with no compile-time checking, so a truthy non-boolean could opt in by accident |
| a signed artifact to the baseline it was derived from | PR-09's sha256 covers figures derived against the committed baseline; a baseline rewritten between generation and signature invalidates the signature silently |

No package is installed and no network route is added, so the Package Legitimacy Gate and a
`T-36-SC` row do not apply to this plan.
