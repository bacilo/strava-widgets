   - TRAVERSAL, DELIBERATELY DIFFERENT: production is `classifyPairKinds`' three-pass, strict-priority,
     pair-index shape with a pass-3 detector overwrite. This recount is interval-first: it
     enumerates non-covered INTERVALS from the raw series (recording gaps, then zero-advance pause
     runs, then over-speed runs), merges them, and derives covered metres and seconds as the
     COMPLEMENT — the opposite direction from production's covered-run accumulation.

     was copied from, and state that duplicating them is the price of independence.
   - THE BOUND ON ITS CLAIM: this recount verifies that the shipped running pace's metres and

     cannot arbitrate the D-05 disagreement threshold — that is the calibration script's job, which
     legitimately DOES import the running-pace function because arbitration is its purpose.
2. Reader: enumerate `data/streams/*.json` directly with `readdirSync`/`readFileSync`. Skip any file
   that does not parse or whose `t`/`d` are not equal-length arrays of at least two finite,
   non-decreasing numbers, counting each skip by reason. Never throw on a bad file.
3. Recount, per activity, interval-first:
   a. Recording-gap intervals: every consecutive pair with `dt > LOCAL_GAP_THRESHOLD_SEC`.
   b. Pause intervals: maximal runs of consecutive zero-advance pairs whose total duration exceeds
      `LOCAL_PAUSE_MULTIPLIER * p90(advance intervals)`, with p90 computed by this script's own
      local R-7 quantile implementation — a LOCAL duplicate of the shape, so the recount does not
      share `quantile`'s vocabulary with the code under test.
   c. Over-speed intervals: maximal advancing runs whose aggregate implied speed exceeds
      `LOCAL_SPEED_LIMIT_MPS`, plus any pair adjacent to a recording gap that the same aggregate
      rule condemns — mirroring the detector's merge intent without reusing its traversal.
   d. Merge (a)+(b)+(c) into a set of non-overlapping excluded pair-index ranges.
   e. `recountExcludedSec` = the summed duration of those pairs; `recountExcludedM` = their summed
      `d` advance; `recountCoveredSec` = `spanSec - recountExcludedSec`;
      `recountCoveredM` = `(d[n-1]-d[0]) - recountExcludedM`;
      `recountRunningPaceSecPerKm` = `recountCoveredSec / (recountCoveredM / 1000)` or `null`.
   f. Emit per-activity rows for the four named IDs (`3475724402`, `3475734189`, `3475740390`,
      `5059204779`) and archive-wide aggregates for every activity.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed stream archive to the recount | Every `data/streams/*.json` is parsed JSON of unverified runtime shape; a truncated or hand-edited file must be skipped and counted, never crash the sweep or silently distort an aggregate |

`T-35-SC` row do not apply to this plan.
