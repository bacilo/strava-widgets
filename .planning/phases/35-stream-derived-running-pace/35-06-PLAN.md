## THE PRE-DECLARATION (D-05). Written 2026-09-24, before any measurement. Encode verbatim.

### Populations

- **E, the eligible population.** Every archive activity whose `deriveRunningPace` result has
  `computable === true`, whose `metadataPaceSecPerKm > 0`, and whose `excludedM > 0`. The
  `excludedM > 0` clause IS D-02's eligibility gate: ZERO free parameters, so it cannot be tuned
  toward a count. It is a mechanism filter (did the computation withhold any distance at all?), not
  a magnitude filter. Rationale: the badge is this milestone's claim about distance covered off the
  clock; an activity that withheld no distance at all disagrees for a different reason, which is
  `elapsedVsMoving`'s territory and an explicit Deferred Idea of this phase.
- **C, the tight control.** Every activity with `computable === true`, `metadataPaceSecPerKm > 0`,
  `excludedM === 0` AND `excludedSec === 0` — nothing withheld in either unit.
- **B, the broad control.** Every activity with `computable === true`,
  `metadataPaceSecPerKm > 0` and `excludedM === 0`; seconds may have been withheld.

C and B are each DISJOINT from E by construction (`excludedM === 0` versus `excludedM > 0`). That
disjointness is the non-circularity argument: a cut derived from C or B is derived from a population
that provably contains no activity with distance covered off the clock — precisely the mechanism the
badge detects. Encode the disjointness as an assertion, not a comment.

### Per-activity statistics

`delta = runningPaceSecPerKm - metadataPaceSecPerKm` (sec/km; positive means the running pace is
slower). `ratio = runningPaceSecPerKm / metadataPaceSecPerKm` (positive, dimensionless).
Direction is SLOWER-ONLY (D-06): only `delta > 0` / `ratio > 1` can badge. Percentiles use the
repo's ONE R-7 `quantile` definition (`pace-derivation.ts`), re-declared locally in this script
only if importing it would violate nothing — check and state which was done.

### Shapes, in first-clearing order

| Id | Base population | Statistic | Cut |
|----|-----------------|-----------|-----|
| S0 | E (STRAWMAN, must FAIL) | `delta` | `delta(3475724402)` minus the smallest positive gap between adjacent `delta` ranks in E |
| C1 | C | `delta` | `quantile(sorted(delta over C), 0.95)` |

**Ordering rationale, declared before measurement:** at each quantile the `delta` sibling precedes
its `ratio` twin, because D-07 records that an absolute sec/km difference is directly readable in
the disclosure sentence and in the same unit as every pace figure on the page. q95 precedes q99
because a q99 over a control is strictly more tail-sensitive, and D-13's own axes will punish that,
so the more robust reading is offered the chance first. Control C precedes control B because C
provably excludes both disagreement mechanisms while B excludes only the distance one.

**S0's circularity, stated:** it reads the constant off the very activity ROADMAP criterion 3
requires to be badged, so it cannot fail to badge it and is evidence of nothing. If S0 CLEARS the
insensitivity axes, the round is invalid and the generator must render `## NO SHAPE CLEARS` with
`strawmanCleared: true` stated as the reason, never proceed to the real shapes.

### D-13 insensitivity. Tolerance fixed at 1%. Never widened, on any axis, for any reason.

- **Axis A — judged-contribution removal.** Re-derive the cut with the badged population's
  contribution removed from the shape's base population. For every C- and B-based shape this is
  STRUCTURALLY ZERO, because the base population and the badged population are disjoint by
  construction. The artifact must render that row as `structural (0 by construction)` and it must
  NOT count as a pass — a row that cannot fail is not evidence. For S0 this axis genuinely bites.
- **Axis B — proportional planting.** Plant `ceil(0.01 * N)` synthetic members into the shape's OWN
  base population, N being that population's size in its own unit. Each plant carries the base
  population's observed maximum statistic value — the most adversarial placement for a high
  quantile. Every plant must enter the population the shape actually reads, asserted as
  `planted items === base items + plants entered` for every shape including S0 (34 D-19's fix for
  HALT-1's vacuous rows).
- **Axis C — base-tail removal.** Remove the base population's `ceil(0.01 * N)` largest-statistic
  members and re-derive.

A shape CLEARS only when Axis B and Axis C both move the cut by no more than 1%. Axis A is rendered
with its status, never counted.

### Arbitration and the basis gate

First-clearing: evaluate S0 first (must fail), then C1, C3, C2, C4, B1, B2 in that order, and ship
the FIRST shape that clears. The archive-wide badged count may never select, tune or re-order a
shape (Phase 27 D-02 anti-quota).

**Basis gate, applied AFTER arbitration:** the cleared shape's cut must badge 3475724402 under the
eligibility gate and the slower-only direction. If it does not, render `## GATE FAILED` and name no
constant. A different shape is NOT substituted to satisfy the gate — substitution would make the
gate a selector, which is exactly what the anti-quota rule forbids.

### Findings, reported and never used to select

Archive-wide newly-disputed count under the chosen cut; the count on the faster side (running pace
faster than metadata) at the mirror cut, per D-06; the size of the gate-excluded population
(`excludedM === 0`) with its own delta summary, per D-02; the non-computable count with reasons; and
the badged/not-badged status of 3475724402, 3475734189, 3475740390 and 5059204779.
