The agreement bar is FIXED HERE, before any measurement, and is never widened:
- A named activity's recount row AGREES with the shipped `deriveRunningPace` when covered metres and
  excluded metres match within 1e-6 m and covered seconds and excluded seconds match within 1e-6 s.
- Any row outside that bar is a DIVERGENCE. A divergence is closed by naming the structural cause
  (a traversal-shape difference between the interval-first recount and production's three-pass
  strict-priority classification is a legitimate cause; "close enough" is not), never by widening
  the bar. The count of UNEXPLAINED divergences must be exactly 0.
This mirrors plan 34-15's own archive-wide reconciliation, which reported 69 full agreements, 13
divergences each explained by a named coverage-scope cause, and 0 unexplained.

imports the COMPILED function from `../dist/` (so `npm run build` must run first) and compares it
against the committed artifact's parsed table.

Idempotence discipline, from `scripts/compute-pause-classification-calibration.mjs` and this repo's
own recorded lesson: hand-editing a generated artifact silently reverts on the next run. If any
prose in `35-RUNNING-PACE-RECOUNT.md` needs correcting, fix `renderRecountMarkdown` in the script
and regenerate — then prove idempotence again. One clean run is not proof; two consecutive
byte-identical runs are.
