<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| origin/master to the local tree | The nightly CI moves the archive under generated artifacts; a figure frozen before the merge describes a tree that is no longer being served |
| built bundle to the served page | `build-widgets` skips on mtime, so a locally edited `dist/` file can make the served page differ from the code just built |
| artifact figures to checkpoint rows | The rows' whole value is that their Expected numbers come from outside the page; a row sourced from the page certifies only that the page agrees with itself |

No package is installed and no network route is added, so the Package Legitimacy Gate and a
`T-35-SC` row do not apply to this plan.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-50 | Repudiation (evidence gathered against a stale bundle) | the served build | mitigate | The served `assets/index-*.js` digest is captured and compared against the freshly built file, and a mismatch forces a clean rebuild before anything is recorded |
| T-35-51 | Tampering (an artifact silently moving under a merged archive) | both generated artifacts | mitigate | Each regenerated twice post-merge and diffed, each compared against its pre-merge sha256, with a moved constant escalated rather than absorbed |
| T-35-52 | Tampering (a vacuous or unsatisfiable checkpoint row) | Manual-Only rows | mitigate | Every row carries a CAN FAIL and a CAN PASS clause computed live against its own named real input, with the computation recorded in the row |
| T-35-53 | Spoofing (a look-alike activity standing in for a named input) | rows 5, 6 and 7 | mitigate | Each id is discovered by query against the regenerated documents and the discovery method is recorded; no synthetic or nearby substitute is permitted |
| T-35-54 | Repudiation (a `-t` filter matching zero tests reading as a pass) | the Per-Task map | mitigate | Every `-t` row records its matched test count, and a zero count is a failure to investigate |

ASVS L1: V5 is not newly exercised by this plan; it regenerates documents and freezes evidence. The
served build is a static SPA with no auth, session or crypto surface.
</threat_model>
