<objective>
Fix the read gate that makes ROADMAP criterion 3 unsatisfiable, and write the running pace onto
every row.

Purpose: `compute-dashboard-index.ts` only opens an activity's stream for the disagreement check
when its metadata pace is under 200 s/km. 3475724402's metadata pace is 296.0 s/km, so that branch
never executes for it — no comparator or threshold change can badge it while the gate stands. This
is 35-RESEARCH.md's "single most consequential implementation mistake available in this phase", and
the fix is to fold the computation into the stream read the quality-signal block already performs
unconditionally two dozen lines below.

Output: one stream read per activity feeding coverage, quality signals, the running pace and the
disagreement check; a new additive `runningPace` row field; and a publish-time assertion.

Requirement-tick safety: this plan ticks nothing. Skip any end-of-plan `requirements mark-complete`
call.
