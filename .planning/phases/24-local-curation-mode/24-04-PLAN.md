<objective>
Build the serving half of `npm run curate`: a Node-built-ins-only HTTP server that mounts the
already-built `dist/widgets` under `/strava-widgets`, injects the curation overlay's script tag
into `index.html` in-flight, bundles that overlay with the already-installed esbuild into the
gitignored `.curate-dist/`, and serves it from `/__curate/*` outside the mount prefix.

Purpose: D-01's "provably absent" claim is structural, and structure is decided here. The
overlay source lives under `scripts/curate-overlay/`, deliberately outside `tsconfig.json`'s
`include: ["src/**/*"]`, outside every Vite config's input graph, and outside
`build-widgets.mjs`'s widget loop and copy lists — so the publish pipeline is not merely
opted out of shipping it, it is incapable of producing it. D-02's prefix mount is equally
deliberate: root-mounted serving is what let the absolute-asset bug ship green at 15/15 in
Phase 16, and curating against production's URL shape means the overlay cannot silently
acquire a root-relative path dependency.

Output: `scripts/curate-server.mjs`, a minimal `scripts/curate-overlay/index.ts` entry, unit
tests, and the `curate` npm script. The write endpoints are plan 24-06; the overlay's controls
are plan 24-07.
</objective>
