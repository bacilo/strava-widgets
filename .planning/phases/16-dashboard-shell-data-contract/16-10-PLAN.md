Widen the single activity-id validation chokepoint so intervals.icu ids are accepted, and land the regression tests whose absence let the defect ship at 334/334 green.

The verifier proved over HTTP that `/data/activities/i174284902.json` and `/data/streams/i174284902.json` both return 200 with parseable JSON, so the data is fine and the defect is exactly this predicate.

Output: a corrected predicate, `i`-prefixed test cases in both suites, and corrected wording in the two prior plan must-haves that specified the defect.
</objective>
