## Design System

| Property | Value |
|----------|-------|
| Tool | none — shadcn not applicable |
| Preset | not applicable |
| Component library | none — hand-rolled view-registry modules, one per route (CONTEXT.md D-03) |
| Icon library | none — hand-authored inline SVG (hamburger/menu, sun, moon); zero new npm deps |
| Font | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` (existing widget stack, `src/widget/styles.css`) |

**Why no shadcn:** shadcn is a React/Radix component system. CONTEXT.md D-01 locks this phase to vanilla TypeScript with no framework, consistent with all 11 existing widgets and 3 standalone pages (zero new runtime dependencies). The shadcn init gate is therefore skipped by design, not by omission — this was answered upstream, not re-asked.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding |
| sm | 8px | Compact spacing: nav link gaps, list-row internal gaps |
| md | 16px | Default element spacing: card padding, section gutters |
| lg | 24px | Section padding: view container padding, card-to-card gaps |
| xl | 32px | Layout gaps: overview home stat-card grid gaps |
| 2xl | 48px | Major section breaks: between overview home sections |
| 3xl | 64px | Page-level spacing: top-of-page to nav clearance on desktop |

Exceptions: minimum 44×44px hit target on the mobile hamburger menu button and each collapsed-nav link (accessibility touch-target floor; overrides the 4px grid for tap area only, visual content inside stays on-grid).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Usage:
- **Body (16/400/1.5):** activity list row text, stub-view body copy, error-state body copy.
- **Label (14/400/1.5):** nav links, dates, distances, stream-availability badges, low-confidence flags, secondary/meta text. Matches existing widget error/loading text size (`src/widget/styles.css`).
- **Heading (20/600/1.2):** view titles ("Overview", "Activities", stub-view headings), card headers ("Recent Activities", "Headline Stats").
- **Display (28/600/1.2):** headline stat numbers on the overview home (total km, current streak, recent PR count).

Exactly 4 sizes, 2 weights — no additional sizes/weights permitted without updating this contract.

## Color

CSS custom properties, set at `:root[data-theme="light"|"dark"]` (mirrors `ThemeManager`'s Shadow DOM token pattern, applied at document level per CONTEXT.md D-14).

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) `--bg` | `#ffffff` | `#1a1a2e` | Page background (locked, CONTEXT.md D-13, lifted from `theme-manager.ts`) |
| Secondary (30%) `--surface` | `#f5f5f7` | `#242444` | Nav bar background, stat cards, list-row stripe, stub-view panel (default — extends widget tokens; widgets have no "card" concept today) |
| Accent (10%) `--accent` | `#fc4c02` | `#ff6b35` | See "Accent reserved for" below (locked, CONTEXT.md D-13) |
| Text `--text` | `#333333` | `#e0e0e0` | Primary text (locked, from `theme-manager.ts`) |
| Text-secondary `--text-secondary` | `#666666` | `#a0a0b8` | Label-role text: dates, meta, nav links at rest (default) |
| Border `--border` | `#e5e5e5` | `#33334d` | Nav bar bottom border, card borders, table row dividers (default) |
| Destructive `--destructive` | `#dc2626` | `#f87171` | Reserved, **not used in Phase 16** — no destructive UI actions in this phase's scope (activity-exclusion is pipeline-only, no dashboard control yet). Declared now so Phase 17/18 inherit one token instead of inventing a new red. |

Accent reserved for (explicit list — nothing else may use `--accent`):
1. Active nav item indicator (underline/background) and nav link `:hover`/`:focus-visible` state
2. Theme toggle button's active-mode icon
3. Primary CTA link/button ("View Activity" — the proving-slice lazy-fetch trigger) default and `:hover`/`:focus-visible` state
4. Loading indicator/spinner shown while an activity detail fetch is in flight
5. Focus-visible outline ring on interactive elements (nav links, CTA, theme toggle)

Do not use accent for body text, stub-view badges, borders, or any non-interactive surface.

## Phase-Specific Notes

Not part of the template's core contract but load-bearing for planner/executor — carried forward from CONTEXT.md so this file is self-sufficient.

**Nav structure (D-05):** Top nav bar, entries in order: Overview (`#/`), Activities (list), Calendar, Records, Trends. Detail is a drill-in route only, no nav entry. Active entry gets the accent underline/indicator (see Color).

**Responsive breakpoint (discretionary default, per CONTEXT.md "Claude's Discretion"):** Nav collapses to a hamburger-triggered menu below **640px** viewport width. Above 640px, nav renders as a horizontal row. Hamburger button and each menu link honor the 44×44px touch-target exception above.

**Theme toggle (D-14):** Header control cycling light → dark → auto (or a 3-state switch), using the sun/moon inline SVGs. Persists to `localStorage`; defaults to `auto` (`prefers-color-scheme`). Applies via `data-theme` attribute on `<html>` or `<body>` (document-level equivalent of the widget `ThemeManager` semantics), not Shadow DOM — this dashboard uses plain light DOM (D-04).

**Proving slice rendering (D-07):** Landing (`#/`) and/or Activities list render real rows from the index manifest using Body/Label typography and Secondary-surface row treatment. Clicking **View Activity** lazy-fetches detail JSON; while pending, show the accent loading indicator; on failure, show the Error state copy above with Retry; on success, render at minimum the stats header numbers (Display/Heading typography) — full chart rendering is Phase 17 scope, not required here.

**Stub views:** Calendar, Records, Trends render the Empty-state heading/body above inside a Secondary-surface panel, centered, using Heading + Body typography. No accent color on stub panels (reserved list above).
