<objective>
Land the CSS treatment D-13's new cell anchors need, one wave before the anchors themselves, so
the markup change in plan 20-17 cannot ship an unstyled appearance regression.

Purpose: `styles.css` gained a bare `a { color: inherit; text-decoration: underline; }` rule in
this phase (D-06). D-13 puts a real `<a href>` inside Rank, Time, Pace, Age-Grade and Flags on the
PR table and inside Time and Improvement on the progression table. Without a scoped rule, every one
of those values renders underlined — five underlined numbers per PR row, across every distance
table — which is a visible change to the Records screen that D-13 never asked for and that a human
checkpoint would correctly fail. D-13 asks for the gesture surface, not for a text-link appearance.

`display: block` on the same rule is what makes the gesture surface real: an inline anchor covers
only its glyphs, so a modifier-click landing a few pixels off the digits would miss the anchor and
fall back to the row listener, which refuses modified clicks by design — reproducing exactly the
R18/R19 failure D-13 exists to close.

Output: one class rule in the Phase 20 block, its banner rationale, and guards in the shape plan
20-14 just established for the other seven Phase 20 rules.
</objective>
