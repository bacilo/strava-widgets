| row data -> anchor href | `row.activityId` is interpolated into a hash URL by `activityDetailHref` and written to `anchor.href`. The values are pipeline-generated numeric or `i`-prefixed ids, and the `#` prefix means the value can never become a `javascript:` URL. |
| row data -> accessible name | The curated label is built from `formatActivityDate`, a fixed `DISTANCE_LABELS` entry and `formatEffortDuration` — no athlete free text reaches these cells, and everything is written with `setAttribute` / `textContent`, never an HTML string. |
| seven anchors per row -> keyboard focus order | Every added anchor is a potential tab stop. `tabIndex = -1` is the only thing keeping the row at one stop, and nothing in this repository can observe focus order. |
