## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fetched public JSON → DOM | Exclusion `reason` strings and activity ids are rendered into the page |
| in-page navigation controls → the hash router | Any `href="#..."` would be parsed by `router.ts` as a route |
| activity id → `#/activity/{id}` link | Ids come from the published index and are interpolated into hrefs |
