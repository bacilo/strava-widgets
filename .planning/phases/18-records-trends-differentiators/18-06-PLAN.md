## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL hash query string → view dispatch | `?tab=` is fully user/attacker-controlled and keys a mount dispatch |
| fetched public JSON → parsing | `data/stats/*.json` bodies are parsed with `JSON.parse` and walked by key |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-TAB-01 | Tampering | `parseTrendTab` | mitigate | Exact-match allow-list against `TREND_TAB_KEYS` with a `volume` default; asserted against `__proto__`, `constructor`, wrong case, empty and oversized inputs. Same pattern as `list-logic.ts`'s `SORT_KEYS` |
| T-18-PROTO-02 | Tampering | `parseYearOverYear`, all `parse*` helpers here | mitigate | Own-property reads only; `__proto__`-keyed input asserted unreachable |
| T-18-DOS-02 | Denial of Service | `buildYearGrid`, `computeRollingTotals` | accept | Bounded by the archive (366 cells, 1,868 rows) and by a caller-supplied year; no unbounded loop is reachable from a query parameter. `parseVolumeGranularity` and `parseTrendTab` clamp their inputs before any loop bound is derived |
| T-18-HONEST-01 | Integrity (fabricated data) | year heatmap tint, YoY zero-vs-gap | mitigate | Tint step 0 renders with no accent so a rest day is visibly empty; the bar-chart zero-vs-line-gap distinction is documented in code so the Cadence & HR tab does not copy the wrong convention |
| T-18-SC | Tampering | npm/pip/cargo installs | mitigate | Zero package installs authorized. The heatmap is a plain CSS grid; `chartjs-chart-matrix` is explicitly rejected. An executor that concludes an install is necessary must stop and run the Package Legitimacy Gate |
