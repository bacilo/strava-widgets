<objective>
Wire the three new compute steps into the CLI, the `compute-all-stats` chain, the npm scripts and the nightly CI workflow, then extend the publish verifier to assert every new data file is actually reachable in production (D-20, D-22).

Purpose: `.planning/STATE.md`'s standing lesson from Phase 16 is that a phase gate can report all-green on a broken build when it asserts a local shape production does not have. A data file that computes perfectly on the developer's machine but is never generated in CI — or is generated but never copied — 404s in production and every view that reads it silently degrades. This plan closes both halves of that path.
Output: a wired pipeline and an extended publish contract.
</objective>
