detector's merged output through `pace-derivation.ts`. Prove the mechanism join exhaustive and the
detector read load-bearing. Change no existing output.

Purpose: this is the phase's highest-risk seam (34-RESEARCH.md Pattern 1, Pitfall 1). Every
`'unreliable'`-kind `gapIntervals` entry looks the same whatever its mechanism. A classifier that
speed-classifies them all would label every GPS jump "transported". The mechanism lives only on
`segments`, one join away. Band values do not exist yet, since plans 34-04 and 34-06 calibrate
them. So every function takes its bands as an argument, and tests use a disclosed synthetic
`TEST_BANDS`.

`pace-derivation.ts`, and two new describe blocks in the single-source audit.

checkout, or in a worktree only with `node_modules` symlinked and `data/` copied read-only (the
worktree-executors lesson). A fixture failure in a bare worktree is not a regression.

and STOP-01. Plan 34-11 alone sets dispositions.
