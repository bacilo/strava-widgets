Counts cover recording-gap, merged-segment and zero-advance-pause intervals; covered-creep is NOT counted here (it belongs to forgottenStop). No tier field
- `export interface ForgottenStopSignal { computable: boolean; reason: string | null; count: number | null; totalSec: number | null; longestSec: number | null; creepCount: number | null; creepTotalSec: number | null; creepLongestSec: number | null; pauseCount: number | null; pauseTotalSec: number | null; pauseLongestSec: number | null }`. - `PaceQualityShard.pauseIntervals: { source: PauseSource; pauseClass: PauseClass; startSec: number; endSec: number; seconds: number; metres: number; startMetres: number }[]` and `PaceQualityShard.pauseIntervalsTruncated: boolean`
- `export function projectPauseIntervals(classified: readonly ClassifiedPauseInterval[], creep: readonly PauseInterval[]): { entries; truncated }`. Merges both sources, gives creep `pauseClass: 'stationary'`, sorts by startSec, caps at 100
- Not-computable literals: `pauseClassification` all-null; `forgottenStop` `{ computable: false, reason: <the top-level reason>, all numbers null }`
