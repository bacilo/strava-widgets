COMMON DEFINITIONS (every family)
- Archive: every file in `data/streams/` passing `isStreamFile` (`scripts/lib/stream-files.mjs`),
  sorted by id. Per activity: `r = classifyGapsWithSegments(t, d)`. An activity with
  `r.coverage.spanSec === 0` is not computable, is counted and reported, and contributes to no
  population.
- J (the judged population, what the bands judge): per activity, the `collectPauseIntervals`
  intervals with source `recording-gap` or `merged-segment`, with speed = metres / seconds.
  Zero-advance pause intervals are NOT in J. They are stationary by definition and never judged
  by a band (D-01).
- Covered pair: a pair `i` with `startIndex <= i < endIndex` for some `CoveredRun`, and
  `t[i+1] - t[i] > 0`. Pair speed = `(d[i+1] - d[i]) / (t[i+1] - t[i])`. Its span is
  `[t[i], t[i+1]]`.
- Folded covered step: `advanceSteps(t, d, spans)` from `dist/analytics/unreliable-segments.js`,
  with `spans` = `r.coverage.gapIntervals` mapped to `{ startSec, endSec }` (all three kinds, so
  steps are wholly in covered time). Step speed = metres / seconds. Its span is `[startSec, endSec]`.
  This is the SAME folded-step definition Phases 32/33 calibrated on, and no second folding
  implementation exists.
- Every percentile is the ONE imported R-7 `quantile` over a sorted-ascending copy. Only two
  orders appear: 0.90 (32-CONTEXT D-10(a)'s locked outer order) and 0.50. No new free order.
- R = `RECORDING_GAP_ABS_THRESHOLD_SEC` (imported, 10 s), reused as a neighbourhood width and not
  tuned. The neighbourhood of an interval is `[startSec - R, endSec + R]`.
- Families run in the fixed order G, then M, then W. Downstream families use the upstream chosen
  value AS SHIPPED (rounded, below). If a family HALTs, every downstream family renders "not
  computed: upstream HALT".

D-13 HARNESS (one harness for every shape and strawman)
- TOLERANCE = 0.01 (1%), fixed before any check. A delta is `|perturbed - base| / |base|` on RAW
  unrounded values. A null base, a zero base or a null perturbed value (an emptied population)
  is a FAIL. An emptied population is the most extreme sensitivity there is.
- REMOVED view, G and W families: drop every reference-population item whose span intersects the
  neighbourhood of any J interval of the same activity.
- REMOVED view, M family: drop every item whose span intersects the neighbourhood of any creep
  candidate of the same activity. A creep candidate is a maximal run of consecutive covered pairs
  each with pair speed <= the shipped G value, of any duration.
- PLANTED view (all families): the source shapes are `{ metres, seconds }` of every J interval on
  **3475724402** (real shapes, no synthetic look-alikes). Clone them round-robin into activities
  sorted by id until the planted count equals the archive-wide |J|, which at least doubles the
  J-like contamination. Each plant enters every population of its family as ONE item of that
  population's unit, with speed = metres / seconds. For cadence-gated populations the plant is
  treated as cadence-silent (worst case). For M shapes it is one extra advance interval of length
  `seconds` in that activity. For duration populations it is one extra duration of `seconds`.
  Denominators and per-activity statistics are re-derived on the perturbed view, never held fixed.
- Non-vacuity, asserted before any delta is trusted and rendered in the artifact: removed item
  count > 0, planted count = |J| > 0, source shape count > 0, and the number of activities whose
  population changed under each perturbation.

G FAMILY: stationary/walked boundary = STOP-02 near-zero threshold (D-07). Shipped as
`STATIONARY_MAX_SPEED_MPS`, raw value rounded UP to 3 significant figures (`ceilToSignificant`,
imported from `scripts/compute-unreliable-segment-severity-calibration.mjs`).
ORDER (criteria in priority: (1) stillness is decided by a channel the classifier never reads;
(2) no activity dominates; (3) fewest inherited caveats):

G1: "cadence-silent covered pairs, pooled".
  Population: every covered pair whose two samples BOTH carry a finite cadence value exactly 0,
  pooled archive-wide. Statistic: R-7 p90 of their pair speeds.
  Meaning: 90% of the odometer's advance rates while the athlete takes no steps sit at or below
  it. Above that, something is moving.
  Non-circularity: membership is decided by the cadence channel, which no detector, pause rule,
  classifier or band reads. Covered pairs exclude every J interval and pause by construction, so
  J cannot enter the population. The harness measures what remains.
  Why this is not device-family relabelling: 32-CONTEXT D-03's t/d-purity rule, restated for D-10
  by RESEARCH Pitfall 5, forbids "device-family reasoning creeping in", i.e. deciding how a STREAM
  is treated from what kind of recorder produced it. G1 does not do that. Cadence here only
  selects which covered PAIRS enter a calibration sample for one speed cut. It never labels a
  stream or device, never gates a stream into or out of D-10's `recordingMechanismSignature`, and
  never enters the shipped classifier, which stays a pure function of `t`/`d` and reads only the
  derived constant. As Pitfall 5 requires ("Keep the two rules as separate functions with
  separately-stated non-circularity arguments; the D-10 rule only ever gates the STOP-01 flag's
  own computability, never the PAUSE-01 band derivation"), the D-10 rule and this population stay
  separate functions with separate arguments.
  Disclosed caveats: cadence is present on a subset of streams; a cadence of 0 can also be a
  sensor dropout while moving, which inflates the tail. The D-12 anchor gate below exists to
  catch that.

G2: "cadence-silent covered pairs, per activity".
  Population: activities with at least 30 cadence-silent covered pairs. 30 is
  `SIGNATURE_MIN_COVERED_PAIRS`, D-10's own minimum sample count, reused rather than tuned.
  Statistic: per activity, R-7 p50 of its cadence-silent pair speeds; cut = R-7 p90 across
  activities.
  Ranks below G1 on criterion (3) (a two-level statistic) but guards criterion (2): a few long
  cadence-silent activities cannot dominate.
  Non-circularity: as G1, including the device-family relabelling sentence, which the generator
  copies into G2's nonCircularity text verbatim.

G3: "pause-boundary run-in".
  Population: covered pairs whose whole span lies inside `[p.startSec - R, p.startSec]` or
  `[p.endSec, p.endSec + R]` of some zero-advance pause interval p of the same activity. Pooled.
  Statistic: R-7 p50 of their pair speeds. It uses the median because the run-in mixes
  deceleration and acceleration pairs, so its upper tail is contaminated by construction.
  Ranks last: membership comes from the pause rule (a duration rule with no speed term, so it is
  independent of any band), but the population is a mixture.
  Non-circularity: the pause rule is Phase 26's duration-only rule; no band or class enters it.

M FAMILY: forgotten-stop minimum duration (D-13 of 34-CONTEXT). Shipped as
`FORGOTTEN_STOP_MIN_SEC`, raw value rounded UP to whole seconds (`Math.ceil`).
Per-activity pause threshold `P_a = PAUSE_GAP_P90_MULTIPLIER x quantile(sorted advance intervals,
0.90)`. This is exactly the scale-relative threshold `classifyPairKinds` applies to zero-advance
runs. Advance intervals are positioned locally in the script (each interval's span is from the
previous advance sample's time to the advancing sample's time), and the BASE view asserts that
the sorted multiset equals `advanceIntervals(t, d)` exactly. A mismatch means the views are wrong,
so throw. Activities with no advance interval are excluded and counted.

M1: "pause-rule scale, conservative". Cut = R-7 p90 across activities of `P_a`.
  Meaning: a creep standstill is recognised at the duration the archive's own zero-advance pause
  rule recognises a standstill, for all but the sparsest-sampled tenth of activities. One duration
  definition for both D-09 sources.
  Non-circularity: `P_a` comes from each activity's full advance-interval distribution (thousands
  of intervals) under Phase 26's calibrated multiplier. No creep stretch, band or class enters it.

M2: "pause-rule scale, typical". Cut = R-7 p50 across activities of `P_a`.
  Ranks second on criterion (2): a typical, not conservative, scale.
  Non-circularity: as M1.

STRAWMAN M: R-7 p90 of the durations (seconds) of all creep candidates archive-wide. It is

W FAMILY: walk/run boundary (D-06). Shipped as `WALK_RUN_BOUNDARY_MPS`, raw value rounded UP to
3 significant figures.
VALLEY DEFINITION (one definition, all W shapes and the W strawman): a histogram over
`[lo, hi)` with `lo` = the shipped G value, `hi` = `UNRELIABLE_SPEED_LIMIT_MPS` (imported), and
bin width 0.1 m/s. Edges start at `floor(lo / 0.1) x 0.1`. Only values in `[lo, hi)` are binned.
Bin i qualifies as a dip iff `leftMax = max(counts before i) > 0`, `rightMax = max(counts after i)
> 0`, and `counts[i] <= 0.5 x min(leftMax, rightMax)`. That prominence test is the one
`findValley` already uses. The valley is the qualifying bin with the LOWEST count (ties go to
the lowest edge), and its value is the bin centre, edge + 0.05. No qualifying bin gives null,
which is a FAIL. This deliberately differs from `findValley`'s first-qualifying rule: the first
qualifying bin is a shoulder of the walking hump, not the minimum. Disclosed property: the value is
quantised to 0.1 m/s, so a delta at or below 1% means the valley did not change bins.

W1: "covered time by speed" (time-weighted). Each folded covered step adds its `seconds` to its
  bin. Pooled archive-wide.
  Meaning: the valley in the athlete's own covered-time speed distribution, D-06's own words.
  Non-circularity: covered steps exclude every J interval, pause and unreliable segment by
  construction (D-06: "disjoint from what it judges"); the harness measures leakage directly.

W2: "covered steps by speed" (count-weighted). Each folded covered step adds 1. Pooled.
  Ranks second: sampling rate biases counts, since a 1 Hz stream contributes more steps per
  minute than a decimated one. It is a structurally different weighting, so it is a genuine
  second opinion.
  Non-circularity: as W1.

STRAWMAN W: the valley over the speeds of J itself (count-weighted). It is circular. Removal
  empties it, so it FAILs.
REJECTED ON ARGUMENT: (a) a per-activity valley percentile: most activities contain no walking
  hump, so the population would be selected by the property being measured; (b) a cadence-split
  anchor, which needs its own uncalibrated cadence constant.
