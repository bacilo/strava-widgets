computed on each candidate's own stream, and record which, if any, the developer confirms as a
genuine walking break. This runs before any control is pinned (D-12).

Purpose: STOP-02 requires that walking breaks are shown not to be flagged. A negative control
that was never really a walk proves nothing, and a control whose window contains a standstill is

the reachability of the future discriminator is computed now, in both directions, on the named
real inputs. It is not computed on a convenient look-alike (the reachability-probe-must-use-named-input
lesson).

developer-authored control file.

| Candidate | Window (t) | Research speed | Research rest-of-activity speed |
|---|---|---|---|

| 3475733231 | t=1827-2229 | 1.512 m/s | 2.462 m/s |
| 3475715143 | t=1590-1992 | 1.797 m/s | 2.435 m/s |

Research flagged that 3475715143's zero-advance ("flat") check was not re-verified with the same
script pass. This plan re-derives it.

The forgotten-stop discriminator that plan 34-03 will build (stated here so the reachability is
computed against the rule that will actually judge the control): a creep stretch is the union of
every window `[t[i], t[j]]` inside one maximal run of covered pairs such that `t[j] - t[i] >= minSec`
(`j` the smallest such index) and `d[j] - d[i] <= maxSpeedMps * (t[j] - t[i])`. So for a given
`minSec`, the control window is flagged iff `maxSpeedMps >= minWindowSpeed(window, minSec)`, where
`minWindowSpeed` is the minimum aggregate speed over every such sub-window inside the walking
window.

Zero-import string-scan guard shape to copy exactly: `scripts/compute-unreliable-segment-recount.test.mjs`
(`FORBIDDEN_MODULE_NAMES` + `stripComments` block-then-line, scanning the script's raw source).
Do NOT substitute a `vi.spyOn(fs, ...)` runtime mock. It cannot observe a named `import { readFileSync }`
and would pass vacuously (the fs-spy-cannot-observe-named-imports lesson).
