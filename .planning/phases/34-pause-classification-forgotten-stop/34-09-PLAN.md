<objective>
Disclose the classification and the forgotten-stop flag on the activity detail view: a Pauses
section (per interval, from the lazy shard) and a one-line untiered summary row in Quality Signals
(from the index row). Add no list badge, no filter and no chart change.

Purpose: PAUSE-02 ("the detail view lists each pause with its class, duration and distance") and
STOP-03 ("disclosed on the detail view") are rendered claims. This plan builds pure plan functions
that tests assert on without a DOM, plus thin textContent-only builders, in the project's
established `*SectionPlan` / `build*Section` split.

Output: shard entry parsing, the summary row, the Pauses section, its mount, and the D-17 badge guard.

Copy (Claude's Discretion, recorded here so the executor does not invent it):
- Section heading "Pauses". Table columns in order: "At" (elapsed `m:ss` from the shard's
  startSec, formatted like the Unreliable Segments evidence text via `formatEffortDuration`,
  followed by " · km <startMetres/1000 to 2 dp>"), "Class", "Duration" (`formatEffortDuration(seconds)`),
  "Distance" (metres to whole m).
- Class labels: "Stationary", "Walked", "Ran through", "Transported". A covered-creep row's class
  cell reads "Stationary — possible forgotten stop (timer running)". A zero-advance-pause row's class
  cell reads "Stationary — paused (timer running)".
- Empty state, when the shard is present with zero entries: "No pauses or recording gaps in this
  activity." Shard absent: "Pause detail unavailable."
- Truncation note: "Showing the first 100 intervals."
- A one-sentence legend under the table: "Class is judged from each interval's own distance over
  its own elapsed time. GPS jumps are not listed here; see Unreliable segments."
- Summary row label "Pauses". Value, when computable: "<n> intervals: <a> stationary, <b> walked,
  <c> ran through, <d> transported · possible forgotten stop: <k> stretches, <T> total, longest <L>
  (creep <kc>/<Tc>, paused <kp>/<Tp>)". With zero stretches the forgotten-stop part reads
  "possible forgotten stop: none found". When forgottenStop is not computable it reads "possible
  forgotten stop: not computable — <reason>".
</objective>
