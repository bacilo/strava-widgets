## 22-10: `npm test` fails on 5 unrelated suites in this worktree — missing generated data files

**Found during:** Task 3 verification (`npm test` run as part of the plan's chained verify command).

**Symptom:** 5 test files fail at import time with `ENOENT: no such file or directory,
open 'data/stats/<name>.json'`:
- `src/dashboard/views/records-logic.test.ts`
- `src/dashboard/views/trends-cadence-hr-logic.test.ts`
- `src/dashboard/views/trends-gear-logic.test.ts`
- `src/dashboard/views/trends-training-load-logic.test.ts`
- `src/dashboard/views/trends-yoy-logic.test.ts`

**Root cause:** `data/stats/` is gitignored (`.gitignore:11`) — it is generated by
`npm run compute-all-stats`, which runs the full data pipeline against the committed
activity archive. This worktree is a fresh checkout with no generated `data/stats/`
directory, so these 5 suites (which read live JSON at module scope, by design —
see their own header comments) cannot import.

**Scope:** None of these 5 files are in plan 22-10's `files_modified` list
(`src/dashboard/storage.ts`, `storage.test.ts`, `calendar-preferences.ts`,
`calendar-preferences.test.ts`, `calendar.ts`, `calendar.test.ts`). Confirmed
pre-existing and environment-caused, not a regression from this plan's changes —
`data/stats/` is absent regardless of any edit made in this session.

**Not fixed:** Generating `data/stats/` requires running the full stats pipeline
(build + `compute-all-stats`, which itself depends on the committed activity
archive and, per `data/provenance.json`, the intervals.icu-migrated ingestion
path) — well outside plan 22-10's scope and files_modified list.

**Verification substitute:** All three files this plan touches or depends on —
`src/dashboard/storage.test.ts`, `src/dashboard/views/calendar-preferences.test.ts`,
`src/dashboard/views/calendar.test.ts` — pass in full (74 tests, 0 failures), and
`npx tsc --noEmit -p tsconfig.json` exits 0. The remaining 47 test files that do
not depend on `data/stats/` all pass (1143 tests), so no test regressed as a result
of this plan's changes.
