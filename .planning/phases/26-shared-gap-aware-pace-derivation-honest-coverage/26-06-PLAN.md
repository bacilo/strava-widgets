<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| derivation result → rendered DOM | Coverage numbers and gap durations become user-visible claims; a wrong number here is a false statement of fact, not just a cosmetic defect |
| `Split` timings + `GapInterval` timings → annotation arithmetic | Two independently-derived time ranges intersected; an off-by-one attributes a gap to the wrong kilometre |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | Denial of Service | `buildBreakdownSection`, `buildSplitsSection` | mitigate | `coverageCaptionText` returns `null` on a non-positive span and the caller appends nothing; `splitGapAnnotations` returns `[]` for empty or malformed input; neither helper throws, and `buildBreakdownSection` keeps its existing `null` return when there is nothing to show |
| T-26-02 | Tampering | displayed percentages | mitigate | Percentages are computed from unrounded seconds and rounded only for display; no `?? 0` substitution, and the tests pin that the three rounded values are not adjusted to force a 100% sum |
| T-26-12 | Repudiation | on-screen coverage claim | mitigate | The caption reads from the same single derivation result the histogram consumes (D-16), so the displayed number cannot be sourced from a second, differently-computed value; plan 26-10's checkpoint reconciles it against a hand-sum of the committed stream file |
| T-26-13 | Information Disclosure | accessibility | mitigate | The `⚠` glyph is `aria-hidden` and always paired with a text equivalent — the cell's `aria-label` and the legend line — so meaning is never carried by a glyph or a colour alone |
| T-26-SC | Tampering | npm/pip/cargo installs | mitigate | No package installed; 26-RESEARCH.md records the gate as not applicable. Any new dependency requires re-running the Package Legitimacy Gate protocol |
</threat_model>
