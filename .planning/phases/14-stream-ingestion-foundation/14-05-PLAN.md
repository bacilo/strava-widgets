## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| intervals.icu live API → reconciliation branch | Third-party responses for activities the local export never covered |
| `INTERVALS_API_KEY` env var → local CLI | A real credential read from `.env` on the developer machine |
| backfill output → permanent git history | Committed blobs cannot be cheaply removed once pushed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-05 | Denial of Service (repo bloat) | committed `data/streams/` | mitigate | `formatSizeReport` prints total MB, the ten largest files, and a `WARNING:` line above the 50 MB budget; the blocking human checkpoint requires the developer to inspect it before staging anything. The command never commits on its own. |
| T-14-13 | Elevation of Privilege | reconciliation branch credentials | mitigate | Missing `INTERVALS_API_KEY` skips the branch with a log line instead of throwing or prompting; the key is passed only into `IntervalsClient` and never logged or written to any output file. |
| T-14-01 | Denial of Service | reconciliation loop | mitigate | Per-target `try`/`catch`; a 404 from an activity past the retention window settles as `no-original` rather than aborting the run and discarding the FIT/GPX work already completed. |

| T-14-SC | Tampering | npm installs | accept | Zero new packages this phase (RESEARCH.md Package Legitimacy Audit: not applicable). No legitimacy checkpoint required. |
