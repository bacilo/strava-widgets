`export function recountDemotedActivities(bestEffortsDoc, exclusionsDoc)` returning
`{ flaggedActivityCount, flaggedActivityIds, excludedWithinFlaggedCount, exclusionsTotal }`.

- Guard `bestEffortsDoc.activities` exactly as `recountDemoted` does (default `{}` when absent or
  not an object), default `efforts` to `[]` when not an array, and treat a `demotion` that is not a

  existing `recountDemoted` already reports malformed guards separately via `unrecognisedGuards`).

  stable across runs and diffable); `flaggedActivityCount` is its length.
- When `exclusionsDoc` is null/undefined, `excludedWithinFlaggedCount` and `exclusionsTotal` are
  `null`. Otherwise read `exclusionsDoc.exclusions` with the same `Array.isArray` guard used
  elsewhere, count entries whose `activityId` is a string (that is `exclusionsTotal`), and count how
  many of those ids are in the flagged set (that is `excludedWithinFlaggedCount`). Never subtract:
  D-02 makes the excluded set a marked subset of the flagged set, not a deduction from it.
- Add no new `import` to this file — the `zero-import guard (D-15)` describe block asserts the
  script names none of the four forbidden modules, and that guard must stay green.

Add a JSDoc docblock stating in one sentence that this count is deliberately derived by this script's
