<objective>
Build the curation UI itself: the tickbox, the required-reason textarea, Save, Remove exclusion
and Recompute records, injected into the real "Best Efforts This Run" panel the developer is
already reading — the original todo's instinct, "perhaps in the line of the PRs".

Purpose: two design constraints do most of the work here. The overlay must never become a second
renderer for the panel (D-03's rejected alternative, and Phase 21 D-05's drift-seam argument), so
after a successful write it calls `location.reload()` and lets the existing, untouched
`detail.ts`/`detail-sections.ts` renderer repaint the `Excluded — {reason}` badge from the
freshly mirrored file (OD-1). And it must ship zero CSS: `src/dashboard/styles.css` already
carries Phase 19's bare-element `input`/`textarea`/`button` baseline, and its
`input[type="checkbox"]` comment names "Phase 24's curation UI" by hand, so plain elements
inherit the full box, hover, disabled and two-tone focus-ring treatment for free (OD-3).

Output: `mountCurationControls`, the network layer, and a source-structure guard pinning the
contract — the only kind of proof possible here, since this repo has no DOM test environment.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| overlay (in-page script) -> curate write endpoints | The overlay is the only intended client of `/__curate/*`; the server must not trust it |
| overlay -> the published dashboard's DOM | The overlay augments a panel it does not own and must not couple to its internals |
| overlay bundle -> publish pipeline | `.curate-dist/` and `scripts/curate-overlay/` must remain unreachable from `dist/widgets` |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-24-OVERLAY-XSS | Tampering | injecting the stored reason into the panel | mitigate | Every DOM node is built with `createElement` + `.textContent`; `innerHTML` is banned and asserted absent, so a reason string can never be parsed as markup |
