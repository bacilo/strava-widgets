asserts that `/__curate/health`, `/__curate/overlay.js` and the write endpoint all 404 over the

artifact into `dist/widgets` and watching the shipped script exit non-zero.

assertion "demonstrably fails against a build that regresses this". This repo has twice recorded
guards that stayed green when the thing they guarded was removed (Phase 19 R3-CR-01, Phase 23
WR-06). A guard that has never been seen red is not evidence here.

is PUBLIC. `build-widgets.mjs:163` copies it, `detail.ts:465` and `records.ts:56` fetch it, and
`verify-dashboard-publish.mjs:294` already asserts it 200s and parses. Only the WRITE path is
private. The new guards must be scoped so they cannot possibly catch it.

Output: three new `expect404` calls in the shipped verifier and a subprocess planted-fixture test.

CONSEQUENCE FOR PATH SHAPE (verified by reading safeResolve)
