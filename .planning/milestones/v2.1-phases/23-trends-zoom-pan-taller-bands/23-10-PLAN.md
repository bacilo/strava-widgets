<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Chart.js scale internals → tick callback | Chart.js supplies the `ticks` array this code derives a step from; the array's shape is the library's contract, not ours |
| browser layout engine → `ResizeObserver` callback | A layout change now schedules application code on every observed resize of a chart wrapper |

No network, storage, process or file-system surface is introduced. Tick text is derived from epoch
numbers already present in `data/stats/*.json` and is written by Chart.js into the canvas, never into
the DOM as markup.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-GC-RO-LOOP | Denial of service | the new `ResizeObserver` callback | mitigate | An observer whose callback changes the observed element's size loops until the browser cuts it off, freezing the tab. The observed element is `.chart-band__canvas-wrap`, whose height is a CSS `clamp()` and whose width comes from its block containing block — neither is content-derived, so `chart.resize()` cannot change it. `chart.resize()` additionally no-ops when the measured size is unchanged. Task 3's comment records this reasoning at the call site so a later change to the wrapper's sizing has to confront it |
| T-23-GC-RO-LEAK | Denial of service (resource) | observer lifetime vs. chart lifetime | mitigate | A `ResizeObserver` holding a destroyed `Chart` keeps that chart and its canvas alive, and its callback would then call `resize()` on a destroyed instance during the rapid tab cycling R17 exercises. Every one of the seven `ChartHandle.destroy()` bodies calls its detach before `chart.destroy()`, inside the existing idempotence guard. R17's Round 2 re-run is what proves it: zero console errors and the per-panel canvas counts still at their design values |
| T-23-GC-TICKS | Tampering (of displayed values) | `stepMsFromTicks` reading a library-supplied array | mitigate | A malformed or single-entry `ticks` array must not produce `NaN`, `Invalid Date` or a thrown error inside a render pass. `stepMsFromTicks` takes the smallest strictly-positive FINITE adjacent difference and returns `0` otherwise; `tickGranularityForStep` maps `0`, negatives and non-finite input to `'month'`; `formatTimeAxisTick` returns the empty string for a non-finite epoch. All four paths are asserted in Task 1 |
