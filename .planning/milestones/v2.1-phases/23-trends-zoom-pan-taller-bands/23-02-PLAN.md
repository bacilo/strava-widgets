    Rules to add, with these exact values:

    - `.chart-band__canvas-wrap--tall` declaring `height: clamp(200px, 34dvh, 420px);`
      D-19's viewport-relative shape. `dvh` rather than `vh` because mobile Safari recomputes
      `vh` as the address bar collapses during scroll, which fires Chart.js's ResizeObserver and
      visibly resizes the chart mid-scroll (23-RESEARCH.md Pitfall 6); `dvh` has been supported
      in Safari since 15.4 and Chrome since 108. 200px floor roughly doubles today's 140px on a
      short window; 34dvh is ~230px on a 13-inch laptop and ~420px on a tall external monitor,
      where "a page with room to spare" is literally true; the 420px cap stops a 4K display from
      turning one band into a full screen.

    - `.chart-band__header--zoom` declaring `flex-wrap: wrap;` and `gap: var(--space-sm);`
      A Trends-only header modifier. It exists because the shared `.chart-band__header` rule has
      no `flex-wrap`, and at 390px the band title plus five buttons plus the D-17 hint cannot fit
      on one line. Adding wrap to the shared rule would change the activity detail view's overlay
      picker header - exactly what D-18's discipline forbids.

    - `.chart-zoom-controls` declaring `display: flex;`, `align-items: center;`,
      `flex-wrap: wrap;`, `gap: var(--space-xs);`
      D-10's cluster: a single second flex child of the header, holding the hint and the five
      buttons. The buttons themselves need no class - Phase 19's bare-`<button>` baseline already
      supplies size, radius, hover, disabled and focus-ring treatment.

    - `.chart-zoom-hint` declaring `color: var(--text-secondary);` and `font-size: 13px;`
      D-17's persistent modifier hint. It stays visible at every width (it is never hidden by a
      media query) - a checkpoint row reads it back, and hiding it at phone widths would make
      D-14's modifier-gated wheel zoom undiscoverable exactly where discovery is hardest.

    THIS ORDER:
      1. `.chart-zoom-hint` declaring `font-size: 12px;`

    RULE_SCANNER swallows an at-rule block's FIRST nested rule into the prelude's pseudo-body
