## Sampling Rate

- **After every task commit:** Run the quick run command. Record matched files and test counts.
- **After every plan wave:** Run `npm run test:logic`, then `git status --porcelain -- data`. Expect no unintended data changes.
- **Before `/gsd-verify-work`:** `npm test` green, and `npm run build` (tsc) clean.
- **Max feedback latency:** ~10 seconds.

Baseline counts at HEAD (no `-t` filters): intervals-sync 6, fit-import 30, reconcile 25, reconciliation-audit 9, test-partition 7. After the phase, intervals-sync must be 12 (> 6) and fit-import 39 (> 30: +4 importer edge rows in 01, +5 sync offset rows in 02). The CAN-FAIL test is replaced, not removed. near-match.test.ts must have ≥ 1 test. If any `-t` filter is used, record its matched count, which must be > 0.
