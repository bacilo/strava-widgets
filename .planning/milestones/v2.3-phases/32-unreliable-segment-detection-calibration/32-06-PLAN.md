    - deriveSpeedLimit(archive, statisticLabel) computes the statistic named in the Decision (the same function 32-05 reported for that label, reused and not re-implemented) and returns Math.ceil(value × 100) / 100. Rounding up flags less, never more
    - mustFlagItems(decision) and mustSpareItems(decision) build the named sets from NAMED_ITEMS plus the Decision. must-spare = the trivia window plus the Decision's locked fixtures. must-flag = the hidden pause plus the five jumps (or, under option-amend-criterion-3, the retained subset recorded in the Decision). 4556693525 is in neither set (D-01)
    - deriveExcessFloor(archive, L) derives F by a rule the executor states in its docblock and in the artifact. Round F to 0.1 m in the direction that keeps every must-flag item admitted
    - checkFeasibility(archive, L, F, decision) returns { pass, rows } over mustFlag and mustSpare, using runExcessAt: every must-flag item has excess > F, and every must-spare item is null or ≤ F. Each row records which mechanism excluded a spare item: 'speed limit' (null at L) or 'floor' (excess ≤ F)
    - deriveHiddenPauseBoundary(archive, L, F) histograms the metres of every no-gap segment detected at (L, F) (hiddenPauseMinMetres set to Number.MAX_SAFE_INTEGER so all no-gap segments are collected). Bins are 5 m wide. It searches for a valley: a bin strictly between the largest must-flag isolated-jump segment's metres and the hidden-pause segment's metres whose count is ≤ 0.5 × the smaller of the maximum counts on its left and on its right within that interval. If one exists, B = the lower edge of the lowest such bin, with valleyFound true. If none exists, valleyFound false and B = a fallback rule the executor states (it must lie strictly inside the anchor interval and must not be a tail percentile of segment metres). In both cases it returns { B, valleyFound, histogram, anchorInterval }
    - For each of L, F and B: insensitivityCheck with the fixed 0.01 relative tolerance passes. The corresponding strawman fails the same check, and is watched failing: pooled p99.9 of all folded step speeds for L; R-7 p99 of all detected burst excesses for F; R-7 p99 of no-gap segment metres for B. A passing strawman makes the harness vacuous and fails the task
    - Unit tests on hand-built fixtures: ceil rounding; checkFeasibility naming the blocking item; the valley search finding a valley in a hand-built bimodal histogram and reporting valleyFound false on a hand-built monotone-decay histogram; each strawman failing and each real derivation passing insensitivityCheck on a hand-built population
