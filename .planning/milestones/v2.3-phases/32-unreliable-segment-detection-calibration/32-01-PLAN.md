    - appendToManifest(existing, dir, liveFilenames) adds only filenames absent from existing.files. If any EXISTING key's live digest differs, it returns { ok: false, mismatches: [{ file, expected, actual }] } and never overwrites. On success it returns { ok: true, manifest, added: [...] }
    - checkManifest(manifest, dir) iterates ONLY manifest.files keys and returns { ok, mismatches: [{ file, expected, actual }], missing: [file] }. An unlisted new file in dir is invisible to it (tolerated). A listed file that no longer exists is reported in missing
