## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| build output to publish gate | `dist/widgets` (CI compute + build-widgets) is checked by the gate before deploy; the gate must not normalise a silent omission away | built dashboard JSON (public data) |
| test harness to working tree | planted-removal tests mutate built JSON; must never touch real `dist/widgets` or tracked files | build artifacts |
| export_data CSV to consolidate | the local Strava export (gitignored, semi-trusted) decides what is written into the canonical archive | activity metadata, names, file paths |
| consolidate to data/activities + provenance | tracked archive; a wrong dedupe writes a second activity record | activity records, provenance |
| tests and probe to working tree | must not write tracked files | fixtures |
