<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL hash query string → tab dispatch | `?tab=` is fully attacker-controlled and selects which panel mounts |
| in-page controls → the hash router | Any `href="#..."` would be parsed by `router.ts` as a route |
| fetched public JSON → DOM and canvas | Four published stats documents are parsed and rendered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-TAB-01 | Tampering | tab dispatch | mitigate | `parseTrendTab`'s exact-match allow-list (plan 18-06, tested against `__proto__`/`constructor`/unknown values) runs before any dispatch-table lookup; the default is `volume` |
| T-18-HASH-01 | Tampering (navigation hijack) | tab links, chip row, year select | mitigate | No `href="#..."` anywhere; asserted by `grep -c 'href="#'` returning `0`. Tab changes go through the router's own navigation |
| T-18-RACE-02 | Integrity (wrong-panel render) | lazy import + per-tab fetches | mitigate | `requestToken` increment-and-compare re-checked after every `await`, the same pattern `detail.ts` uses for its activity-to-activity race |
| T-18-CANVAS-01 | Denial of Service (runtime crash) | Chart.js canvas reuse | mitigate | Destroy-and-rebuild on every tab switch and every control change; no in-place dataset mutation (`grep` for `.datasets =` and `.update()` returning `0`); the manual checkpoint cycles all five tabs twice watching the console |
| T-18-XSS-01 | Tampering / XSS | all rendered labels | mitigate | `textContent` only; `grep -c innerHTML` returns `0` |
| T-18-A11Y-03 | Information Disclosure (of meaning) | 371-cell heatmap | mitigate | Cells are non-focusable and non-interactive; one summarizing `aria-label` on the container plus a `View as table` `<details>` carrying the real per-day data — the heatmap's information never exists only in a `title` attribute |
| T-18-SC | Tampering | npm/pip/cargo installs | mitigate | Zero package installs authorized; `chartjs-chart-matrix` explicitly rejected in favour of a CSS grid, asserted by `grep -c chartjs-chart-matrix package.json` returning `0`.
