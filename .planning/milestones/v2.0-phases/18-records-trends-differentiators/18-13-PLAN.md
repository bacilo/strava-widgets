Create `src/dashboard/data/age-grading-client.ts` as a structural copy of `gear-client.ts`:
- `export interface AgeGradingClient { load(): Promise<AgeGradingDocument | null>; reset(): void; }`
- `export function createAgeGradingClient(options?: { baseUrl?: string; fetchImpl?: FetchLike }): AgeGradingClient` — URL `${baseUrl}stats/age-grading.json`, default `baseUrl` `'data/'`. `load()` **never rejects**: a 404, a malformed body, or a body failing validation all resolve to `null`, and a `null` result is not memoized. A missing age-grading document is a legitimate degraded state (D-13), not an error.
- `export function parseAgeGradingDocument(raw: unknown): AgeGradingDocument | null` — total, never throws, own-property reads only. Requires a non-array object with a numeric `schemaVersion`, a boolean `enabled`, and non-array-object `rankings` and `activities`. A document with `enabled: false` is **valid** and must parse successfully — the view needs its `disabledReason`.

Create `src/dashboard/data/age-grading-client.test.ts` mirroring `gear-client.test.ts`: a successful load memoizes; a 404 resolves to `null` and does **not** memoize (a second `load()` issues a second fetch); a malformed body resolves to `null`; a rejected fetch resolves to `null` rather than rejecting; an `enabled: false` document parses successfully with its `disabledReason` intact; `__proto__`-keyed input is not reachable; `reset()` clears the cache.

Create `src/dashboard/views/detail-best-efforts-logic.ts` — pure, DOM-free:
- `export function buildPrBadgeLabels(entry: ActivityBestEfforts | null): string[]` — one label per distance where `wasPRAtTheTime === true`, in `TARGET_ORDER`, formatted `PR — {Display}` with display names `400m`, `1K`, `1 Mile`, `5K`, `10K`, `Half Marathon`, `Marathon`. Returns `[]` for a `null` entry or one with no PR-setting efforts. Efforts with `excludedFromRecords === true` never produce a badge — an excluded effort did not set a record.
- `export interface BestEffortPanelRow { distance: TargetDistanceKey; display: string; durationSec: number; paceSecPerKm: number; isPr: boolean; lowConfidence: boolean; excluded: boolean; agePercent: number | null; ageDerived: boolean; }`
- `export function buildBestEffortsPanelRows(entry: ActivityBestEfforts | null, ageGrading: AgeGradingDocument | null): BestEffortPanelRow[]` — one row per effort the activity produced, in `TARGET_ORDER`, **not** only the PR-setting ones (D-08: "every effort this run produced across all seven distances"). `agePercent` joins from `ageGrading.activities[activityId][distance]`, and is `null` when age-grading is disabled or the effort has no grade — never `0`. `ageDerived` is `true` only for `1k`. Returns `[]` when the activity produced no efforts; the caller renders the named empty state rather than omitting the section.

Create `src/dashboard/views/detail-best-efforts-logic.test.ts` covering: a run with two PR distances yielding exactly two badge labels in `TARGET_ORDER` with the exact `PR — 5K` formatting; a run with an excluded PR-setting effort yielding **no** badge for it; a `null` entry yielding `[]` for both functions; a run with five efforts of which two are PRs yielding **five** panel rows with `isPr` true on exactly two; age-grade joined by `(activityId, distance)` with a missing grade producing `null` not `0`; a disabled age-grading document producing `null` on every row; `ageDerived` true only for `1k`; panel rows ordered by `TARGET_ORDER` regardless of the source array's order; `lowConfidence` and `excluded` passing through unchanged.
