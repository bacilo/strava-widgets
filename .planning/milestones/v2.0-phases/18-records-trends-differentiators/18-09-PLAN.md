- `export function fitRiegelExponent(points: readonly RiegelFitPoint[]): RiegelFit | null` — **the guard first**: `new Set(points.map(p => p.activityId)).size < 3` returns `null`. Then ordinary least squares on `(ln distanceM, ln durationSec)` — the slope **is** the exponent. Return `null` when the x-variance denominator is not positive (all points at one distance). `distances` lists the fitted distances in `TARGET_ORDER` sequence so the UI can name them verbatim per D-11.
- `export function selectFitPoints(rankings: Partial<Record<TargetDistanceKey, readonly PRRankingEntry[]>>): RiegelFitPoint[]` — Claude's-discretion subset, resolved here as **rank-1 entries only, excluding any distance whose ranking is empty**. Rank-1 is the smallest defensible set and the one the UI can name in a single phrase; add a comment saying the subset is named in the UI (D-11 requires the fitted table state which distances it used).
- `export interface RiegelCell { from: TargetDistanceKey; to: TargetDistanceKey; predictedSec: number; isActual: boolean; }`
- `export function buildRiegelMatrix(rankings, b?: number): { rows: TargetDistanceKey[]; columns: TargetDistanceKey[]; cells: RiegelCell[][] }` — rows are the distances with a non-empty ranking (so marathon, which has zero entries, is not a row); columns are **all seven** in `TARGET_ORDER` (so marathon is a column, and per § 4b that column is the only place a marathon time appears anywhere in Records). The diagonal cell carries the actual rank-1 time with `isActual: true`. Every other cell is a prediction from that row's rank-1 time.
