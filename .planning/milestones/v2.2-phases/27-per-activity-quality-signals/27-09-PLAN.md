<objective>
Disclose all five signals on the activity detail view, always, tier-styled — and fetch the
evidence shard exactly once per detail open from the single existing mount point.

Purpose: this is Criterion 3 (a badge on a real flagged activity names the detected condition
and its measured value, read directly off the rendered page) and the fetch half of Criterion 2.
D-08 requires healthy signals to be shown too: a healthy activity visibly saying so is what
stops a reader interpreting silence as good news, and it gives plan 27-10's checkpoint a fixed
set of numbers to read back against the committed shard file.

Output: an always-on "Quality Signals" section beside Pace Distribution, and one shard fetch
wired into `mountBestEffortsAndBadges`'s existing `Promise.all`.
</objective>
