<objective>
Produce the archive-wide before/after PR diff PR-04 requires: every top-10 ranking row that moves and
every `wasPRAtTheTime` flip in both directions, computed from the real full archive, written as a
regenerable committed markdown artifact, and proven to regenerate byte-identically.

Purpose: PR-04 calls a PR moving without the owner seeing it a milestone failure. The diff is the
seeing. Its construction is constrained: `data/stats/` is gitignored and starts empty on every CI
runner, so there is no committed historical `best-efforts.json` to compare against — the only correct
comparison computes OLD and NEW semantics from the SAME live snapshot inside one run, exactly as
`compute-pace-residual.mjs` computes its baseline and adaptive figures side by side.

Output: `scripts/compute-pr-ceiling-diff.mjs`, its test, an npm script, and
`.planning/phases/28-pr-plausibility-ceiling/28-DIFF.md`.

<interfaces>
The shape the diff is computed from, produced by plan 28-05's restructured
`computeBestEfforts(options)` in `dist/analytics/compute-best-efforts.js`:

- `options` includes `activitiesDir`, `streamsDir`, `streamsManifestPath`, `statsDir`,
  `exclusionsPath`, `ceilingStatePath`. Pass a throwaway `statsDir` so the dry run never overwrites
  the real `data/stats/`, and pass the real `ceilingStatePath` only if the run should be allowed to
  report movement — for a dry run, point it at a throwaway path too so the diff cannot rewrite
  committed state.
- The returned `BestEffortsDocument` carries `rankings[distance]` (top-10 `PRRankingEntry` rows with
  `rank`, `activityId`, `startDate`, `durationSec`, `paceSecPerKm`, `lowConfidence`),
  `activities[id].efforts[j]` with `wasPRAtTheTime`, `excludedFromRecords` and
  `demotion: { guard: 'world-record' | 'max-speed' | 'ceiling'; reason: string } | null`,
  `ceilings[distance]`, `rejected[]`, and `totals` including `effortsDemoted`.

Pure helpers importable from `dist/analytics/best-effort-utils.js`: `markPRs(effortsForDistance)`
which is chronological and re-entrant over the whole population, and `rankTopN(entries, n)` which
sorts by `durationSec` then `startDate` and slices. `TARGET_ORDER` and `TARGET_METERS` come from
`dist/analytics/best-effort.types.js`.

How OLD semantics are reconstructed — the exact rule, and the reason it is exact: before this phase,
`computeActivityEfforts` deleted an effort when `isPlausible` failed and there was no ceiling at all.
Every such effort now carries `demotion.guard` of `world-record` or `max-speed`, and every
ceiling-only rejection carries `ceiling`. So the OLD ranked population per distance is: the NEW
document's efforts at that distance, MINUS those whose `demotion.guard` is `world-record` or
`max-speed`, MINUS those whose `excludedFromRecords` is true, with ceiling-demoted efforts RETAINED
because the old code had no ceiling to reject them. Feed that population through `markPRs` and
`rankTopN` to obtain the OLD `wasPRAtTheTime` flags and the OLD top-10. No second archive sweep is
needed, and the artifact must state this reconstruction rule so a reader can audit it.

Precedents to follow, read them rather than re-inventing:
- `scripts/compute-pace-residual.mjs` — `__dirname` construction, `OUTPUT_PATH` under
  `.planning/phases/...`, exported pure functions, `renderResidualMarkdown`'s line-array markdown and
  its `|---|---|` table shape, the guarded `main()`, and per-file try/catch sweep discipline.
- The self-execution guard, verbatim:
  `if (import.meta.url === pathToFileURL(process.argv[1] ?? '').href) { main(); }`
- `27-VALIDATION.md`'s G-01 closure record — the idempotence proof shape (zero non-timestamp diff
  lines on a second run) that Phase 27 skipped at first and had to reopen the phase to close.

Measured expectation, from 28-CONTEXT.md's simulated run at an illustrative K of 1.35: 20 efforts
demoted, 10 `wasPRAtTheTime` flags flipped; per distance as demoted / flags-now / flags-after /
flipped — 400m 15/11/8/5, 1k 4/11/8/3, 1mi 1/14/14/2, 5k 0/21/21/0, 10k 0/16/16/0, half 0/6/6/0.
The 1mi row is the case that settles D-12: one effort demoted, two flags flipped, total unchanged at
14 — an activity that was never a PR became one. These numbers were measured under an ILLUSTRATIVE
multiplier, not the one plan 28-01 chose, so they will not reproduce exactly. Re-measure; do not
carry them forward as expected values.
