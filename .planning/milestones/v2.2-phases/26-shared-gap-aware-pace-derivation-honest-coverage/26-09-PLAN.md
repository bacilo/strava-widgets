  and return the weighted fraction faster than 180 sec/km. Its doc comment must state that this is
  the pre-Phase-26 shipped path, kept deliberately so the after-column is measured against
  something real rather than against an assertion.

  fast mass measured over covered time only, which is Criterion 1's "restricting the histogram to
  covered time" requirement.
- `renderResidualMarkdown(report)` — the new code with no template: emit the intro, tables and
  notes as template strings.
