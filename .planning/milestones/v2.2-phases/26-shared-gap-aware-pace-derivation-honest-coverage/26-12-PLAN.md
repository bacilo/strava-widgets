<objective>
Close the phase's one blocking gap: make the D-08/COV-02 coverage caption actually always-on.

Purpose: `buildBreakdownSection` nests the `Pace Distribution` heading AND the coverage caption
inside `if (buckets.length > 0)` (`detail-sections.ts:481` and `:486`). `PaceCoverage` is computed
independently by `classifyGaps` and can be well-defined and non-trivial when the histogram is
empty. Real archive activity `11865310195` — `streams.available: true` in the live index — hits
this today: `classifyGaps` gives spanSec 18, coveredSec 6 (33%), recordingGapSec 12 (67%), yet
`paceHistogramSamples` returns zero samples, so `buckets.length === 0` and the function returns
`null`. The archive's most gap-dominated stream by proportion discloses nothing. That is the exact
failure D-08's "a healthy run visibly states its own health rather than the reader inferring it
from silence" clause exists to prevent — and this run is not healthy.

Output: the caption's render condition decoupled from bucket presence; a permanent behavioural
regression test for the combination no test covered; and a corrected doc comment (its current
"always renders when there are buckets" framing is itself part of the bug).
</objective>
