<objective>
Ship PACE-07's metadata-vs-stream cross-check as an additive, CI-computed flag on the dashboard
index row.

Purpose: this is a live, visible defect. `data/dashboard/index.json` currently holds
`paceSecPerKm: 112.6` for activity 5059204779, so the dashboard shows 1:53/km — and ranks it as
the archive's fastest run — for a run whose own stream derives 5:51/km. Nothing else in the system
would ever have caught it. This plan detects it and records the disagreement; plan 26-08 puts it on
screen.

Output: `detectPaceDisagreement` in the shared module, a required additive `paceDisagreement` field
on `DashboardIndexRow`, the writer that fills it, and the archive-wide over-fire measurement.
</objective>
