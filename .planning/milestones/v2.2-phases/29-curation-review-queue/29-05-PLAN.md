<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mirrored JSON over HTTP → queue DOM | Activity names and demotion/exclusion reason strings are Strava/intervals.icu- or developer-sourced text, sanitized nowhere else |
| queue page → curate write routes | Every write crosses into `curate-server.mjs`'s validated, origin-gated, atomically-written path |
| another browser origin → this page | A page on another origin must not be able to drive a write through the queue |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-02 | Tampering / Information Disclosure | XSS via activity name or reason text rendered into a row | mitigate | `createElement` + `textContent` only; `innerHTML`/`insertAdjacentHTML`/`outerHTML`/`document.write` are grep-asserted absent; plan 29-06 additionally serves the page under a `script-src 'self'` CSP |
