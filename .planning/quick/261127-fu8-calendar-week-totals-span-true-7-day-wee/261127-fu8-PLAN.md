<objective>
Make the Calendar's week-total column count the true 7-day week across month boundaries. This is the user's request, and it reverses Phase 17 D-13. Today `buildMonthGrid` builds each `weekTotals` row from only the non-null in-month `DayCell`s, so a row where the month starts or ends midweek is missing the other month's runs. Grid cells, `monthTotalM` and grid `runCount` stay in-month only. The sr-only accessible name gets the matching fix.

Purpose: when a month starts or ends midweek, the week totals should show the whole week.
Output: the updated logic, view and tests, plus a probe against the old implementation showing that the new assertions catch the old behaviour.
</objective>
